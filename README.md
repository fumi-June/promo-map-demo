# 梅田・無料イベント地図（デモ）

大阪駅から歩いて行ける無料イベントを、施設ごとの光の柱で表示する地図デモです。
柱をタップ → カード → 「経路案内」で、地下街を含む実際の歩行経路が出ます。

**デモ:**
- 3D（斜め見下ろし・光の柱）: https://fumi-june.github.io/promo-map-demo/
- 2D（真上から・円の中に件数）: https://fumi-june.github.io/promo-map-demo/flat.html

画面右上のリンクで行き来できます。

各ページは1枚のHTMLで完結します。ビルド不要、APIキー不要。

## 中身

- **地図** — MapLibre GL JS + OpenFreeMap Liberty。斜め見下ろし（pitch 60）と3D建物
- **光の柱（3D）** — 1施設1本にイベント件数を集約。高さ `h = 40 + 15·log2(n+1)` m（上限120m）
- **円（2D）** — 大きさは一定にして、円の中に件数の数字を出す
- **歩行経路** — OpenStreetMap の歩行者way から自前グラフを作りダイクストラで探索。
  地下経路は建物に遮蔽されないよう破線のゴースト表示にしている

汎用ルーティングサービスは梅田では使えません。OSRM の foot プロファイルは
footway/corridor を歩行不可として除外するため、阪神梅田本店まで 887m を返します
（実際の地下経路は 316m）。生の OSM データには道があります。

## 現在地からの経路

「経路案内」を押すと位置情報の許可を求めます。許可すると**現在地を起点に**経路を引き直します。
事前生成した経路は大阪駅起点なので、ページ内に歩行グラフ（ノード4825・エッジ5252、gzip 52KB）を
埋め込んでブラウザでダイクストラを回しています。

次の場合は大阪駅起点にフォールバックし、その理由を画面に出します。

- 位置情報を許可しなかった／取得できなかった
- 現在地が梅田の範囲外（グラフの最近傍ノードまで400m以上）

## Googleマップへの遷移（デモ限定）

カードの「Googleマップで開く」は、その施設への徒歩経路を Google マップで開きます。
起点は現在地が取れていればそれを、取れなければ大阪駅を使います。

**Google には経路そのものを渡せません**（URLで渡せるのは起点と終点だけ）。そのため
Google 側が独自に計算した経路が出て、**このデモが表示する地下街経由の経路とは異なることがあります**。
実測でも OSRM の歩行プロファイルは阪神梅田本店まで 887m を返します（このデモは 316m）。
距離が食い違うのはそのためで、画面にもその旨を明記しています。

将来アプリ化する際は、アプリ内で経路案内まで完結させる想定です。

## 掲載範囲

イベント名・開催日・会場と、**施設公式ページへの直リンク**のみを掲載しています。
告知の本文は転載していません。詳細は各イベントの「詳細」から公式サイトでご覧ください。

無料バッジは2段階です。濃色は公式ページに「参加費：無料」等の記載を確認できたもの、
淡色はカテゴリからの推定です。**推定には誤りが含まれます**（実測で、有料イベントが
1件「無料（推定）」として含まれています。多イベント告知ページでどの料金が
どのイベントのものか判定できないため）。お出かけ前に公式ページで確認してください。

データは **2026-08-06 収集**です。**終了したイベントは表示していません**（終了日が収集日より前のもの）。
日付が書かれていない告知は判定できないため残しています。

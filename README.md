# 梅田・無料イベント地図（デモ）

大阪駅から歩いて行ける無料イベントを、施設ごとの光の柱で表示する地図デモです。
柱をタップ → カード → 「経路案内」で、地下街を含む実際の歩行経路が出ます。

**デモ:** https://fumi-june.github.io/promo-map-demo/

`index.html` の1枚で完結します。ビルド不要、APIキー不要。

## 中身

- **地図** — MapLibre GL JS + OpenFreeMap Liberty。斜め見下ろし（pitch 60）と3D建物
- **光の柱** — 1施設1本にイベント件数を集約。高さ `h = 40 + 15·log2(n+1)` m（上限120m）
- **歩行経路** — OpenStreetMap の歩行者way から自前グラフを作りダイクストラで探索。
  地下経路は建物に遮蔽されないよう破線のゴースト表示にしている

汎用ルーティングサービスは梅田では使えません。OSRM の foot プロファイルは
footway/corridor を歩行不可として除外するため、阪神梅田本店まで 887m を返します
（実際の地下経路は 316m）。生の OSM データには道があります。

## 掲載範囲

イベント名・開催日・会場と、**施設公式ページへの直リンク**のみを掲載しています。
告知の本文は転載していません。詳細は各イベントの「詳細」から公式サイトでご覧ください。

無料バッジは2段階です。濃色は公式ページに「参加費：無料」等の記載を確認できたもの、
淡色はカテゴリからの推定です。**推定には誤りが含まれます**（実測で、有料イベントが
1件「無料（推定）」として含まれています。多イベント告知ページでどの料金が
どのイベントのものか判定できないため）。お出かけ前に公式ページで確認してください。

データは **2026-08-01 時点の固定スナップショット**です。イベントは終了しています。
